sample_100_drones.skyc
  A small synthetic show in Skybrush .skyc format (the format Skybrush Studio for Blender
  exports) for trying the importer without Blender: 100 drones take off row by row, expand,
  turn 90 degrees on curved paths, return and land row by row, with looping LED effects.
  Design tab -> "Import Blender / Skybrush show..." -> pick this file.
